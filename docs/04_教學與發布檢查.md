# 教學路線與發布檢查

| 階段 | 同學完成的作品 | 學習重點 |
| --- | --- | --- |
| 1 | 開啟 Main 場景並修改物件 | Scene、GameObject、Component、Inspector |
| 2 | 使用 Move 動作控制物件 | Input Actions、MonoBehaviour、時間與座標 |
| 3 | 接觸物件產生回饋 | Collider、Rigidbody、Trigger；依 2D/3D 使用對應元件 |
| 4 | 可重用收集物與分數顯示 | Prefab、狀態與 UI |
| 5 | 勝利、失敗與重玩 | 遊戲流程與最小驗收測試 |
| 6 | 請 AI 修改一個小功能並 review | 任務規格、版本控制、驗證與解釋 |
| 7 | 建置可玩的短遊戲 | Build Profiles、目標平台與執行驗證 |

## GitHub 公開範本

1. 先完成初始化與最小操作示範，再建立公開 Repo。
2. 檢查 git diff 與待提交內容，確認未包含快取、帳密或不可再散布素材。
3. 本包已採 MIT 並提供 LICENSE；第三方機器人保留 CC0，核對 THIRD_PARTY_NOTICES.md。
4. 推送後在 Settings 設為 Template repository；建立 v0.1.0 標籤。
5. 用 Use this template 建立測試 Repo，完成乾淨開啟與 Build。
6. 學生每人建立自己的 Repo；課程範本更新不會自動同步到已建立的學生 Repo，要另提供更新說明。

本骨架沒有聲稱已完成上述 Editor 或 Build 驗證。第一次教學前由老師完成，將結果放 docs/reports。
