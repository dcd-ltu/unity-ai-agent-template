## 公開 Repo 規劃

1. 建立公開 Repository，名稱建議 unity-ai-agent-template。
2. 提交本包自訂內容、LICENSE 與 THIRD_PARTY_NOTICES.md。
3. 若發布補充資料包，README 明確說明須先建立 Unity 專案；若發布完整可開啟專案，另加入指定 Editor 產生的 Packages、ProjectSettings 與 .meta，完成編譯及 Play Mode 驗證。
4. 檢查第三方資產清單，確認新素材可再散布；保留其原授權。學生的付費素材不能直接進公共範本。
5. 完成 Robot 的貼圖內嵌確認與 Unity 測試後，建立版本標籤與 Release，附上不含 .git 的命名分發 ZIP。
6. 新增貢獻時要求自有貢獻接受 MIT、第三方素材附來源與授權；不能僅因免費下載就認定可公開再散布。

一般使用者從 Release 的命名附件取得固定版本；不以 clone、Code Download ZIP 或 Use this template 代替課堂分發。維護者可 clone 貢獻。
