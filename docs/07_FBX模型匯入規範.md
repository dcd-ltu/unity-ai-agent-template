# FBX 模型匯入規範

本課程所有新匯入與更新的 FBX，必須內嵌模型所使用的全部貼圖，材質定義須隨模型匯出。缺漏者退回重新匯出，不接受另附貼圖作為來源交付替代。純幾何模型若未使用任何貼圖，須明確記錄。

## 資料夾

| 路徑範例 | 用途 |
| --- | --- |
| Art/Models/Robot/Robot.fbx | 內嵌貼圖的來源模型 |
| Art/Models/Robot/Materials/ | 從該 FBX 擷取、供 Unity 使用的材質 |
| Art/Models/Robot/Textures/ | 從該 FBX 擷取的貼圖 |
| Art/Models/Robot/Animations/ | 有需要才建立的額外動畫資產 |

以上路徑以 Assets/_Project 為基準。貼圖與材質集中於模型專屬資料夾，不建立模型專用資產的全域 Textures 或 Materials。獨立 UI、2D 素材依原本分類管理。第三方模型以 Assets/ThirdParty/<來源>/Models/<ModelName> 為根，遵守相同流程及原授權。

## 操作流程

1. 製作者在建模工具的 FBX 匯出設定啟用「Embed Media／Embed Textures」或等效設定。不同工具名稱不同；必須確認匯出器真的支援內嵌。所有被材質引用的貼圖均須包含，不能只包 Base Color。
2. 在獨立測試環境隔離原始外部貼圖，確認接收者只取得 FBX 時，仍能擷取全部預期貼圖。不得僅以模型在原作者電腦顯示正常作為證據。
3. 建立模型專屬資料夾並放入 FBX，在 Unity 6000.3.17f1 等待匯入完成。
4. 選取 FBX，在 Model Importer 的 Materials 設定檢查材質匯入；使用 Extract Textures 將內嵌貼圖擷取到該模型的 Textures，再使用 Extract Materials 擷取到 Materials。若按鈕不可用或預期貼圖未出現，先查明來源內嵌與匯入設定，不得直接跳過驗收。
5. 確認材質對應正確，並依目前渲染管線檢查 Shader 與貼圖插槽。法線貼圖須檢查 Texture Type；金屬度、粗糙度與遮罩通道可能需要正確轉換或指定，不能假定自動匹配。
6. 放入測試場景，檢查比例、朝向、材質、透明、法線與遺漏貼圖。來源內嵌驗證與場景外觀驗證分別記錄。
7. 將 FBX、擷取出的材質、貼圖與對應 .meta 一併提交；原始 FBX 保持內嵌交付版本。

內嵌保證交付貼圖跟隨模型，並不保證建模工具的所有材質節點、程序材質或 Shader 能在 Unity 重現；程序材質需要先烘焙成可交付貼圖。

## 更新既有模型

先檢查既有 .meta、材質 remap 與人工調整，再更新 FBX。不要不加檢查地重新擷取並覆蓋檔案；保留 GUID，確認新舊貼圖名稱與材質對應，再驗證使用此模型的 Prefab 與場景。

## 驗收紀錄（放 docs/reports）

- [ ] 模型名稱、製作者、來源、授權與匯出工具已記錄。
- [ ] 只依靠 FBX，即可取得全部預期貼圖；列出貼圖清單。無貼圖模型明確記錄原因。
- [ ] 材質／貼圖已擷取至該模型資料夾，未分散至全域目錄。
- [ ] Shader、貼圖插槽、法線與必要通道設定正確。
- [ ] Unity 場景外觀驗證通過，附截圖與 Editor 版本。
- [ ] FBX、材質、貼圖與 .meta 均已提交，無失效參照。

未完成的項目標記待驗證；內嵌缺漏則退回重新匯出。
