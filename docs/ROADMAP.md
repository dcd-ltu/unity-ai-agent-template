## 協作流程

CreateFolder 工具目前不在本範本範圍；是否整合留待使用者另行決定。

每項任務寫清楚目標、修改範圍、驗收證據、限制與交接。Issue → feature 分支 → 實作 → 編譯／執行／測試 → PR 審查 → main。失敗先修復重測；沒有 Editor 就標待驗證。新對話先讀 AGENTS.md、PROJECT_STATUS.md、ROADMAP.md 與指定任務。
