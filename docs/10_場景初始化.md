# 場景初始化

適用 Unity 6000.3.17f1。獨立 Editor 小工具，不合併 CreateFolder；不需 Inspector 元件指派，也不在開啟專案時自動執行。

## 操作

1. 從 Release 命名附件取得資料包，合併到已建立的 Unity 專案；等匯入與編譯完成。
2. 執行 `Tools → DCD → 初始化專案場景`，確認來源與目標後按搬移。
3. 有未儲存場景時，選「儲存並繼續」；儲存取消／失敗則停止。
4. `Assets/Scenes/SampleScene.unity` 移至 `Assets/_Project/Scenes/SampleScene.unity`；保留 GUID 與名稱。不刪除原 Scenes 資料夾，也不建立另一個場景副本。
5. 全域建置清單與 Assets 內 BuildProfile 資產的舊路徑更新；保留啟用狀態與順序，不新增原本未在清單的場景，不切換 Profile 或其 override 選項。
6. 檢查已開啟場景的儲存路徑、場景內容與各 Profile，再提交工具／場景／.meta／已改動設定。

## 邊界情況

- 沒有來源且目標已存在：提示無須搬移。
- 沒有來源與目標：提示手動確認；不同 Unity 模板不保證有 SampleScene。
- 來源存在、目標有同名檔案／資料夾／殘留 .meta：停止，不覆蓋。
- Play Mode、編譯或匯入中：選單停用。
- 目標路徑的上層若是檔案而非資料夾、版本控制禁止寫入等，API 失敗時記錄 Console，停止。
- 搬移成功但後續更新失敗：提示部分完成，手動檢查各 Profile，不以再次搬移覆蓋資產。

## Unity 實機驗收（目前未執行）

- [ ] 6000.3.17f1 編譯零錯誤；選單可見。
- [ ] 在乾淨新專案記錄來源 GUID，執行後相同，舊路徑消失。
- [ ] 開啟 SampleScene 並修改，取消不搬移；儲存後搬移，關閉／重開確認修改仍在。
- [ ] 開啟其他未儲存場景：保存或取消行為正確，不切換／關閉場景。
- [ ] 目標同名、殘留 .meta、來源缺少、重複執行均不覆蓋。
- [ ] 目標資料夾缺少時可補建；既有 GUID 不改。
- [ ] 全域清單含啟用／停用 SampleScene；保留每一項順序及狀態。
- [ ] 建立兩個 Build Profiles（含非作用中與不同 override 狀態），檢查引用舊路徑者皆更新，其餘不動。
- [ ] 搬移後已開啟場景可以儲存到新路徑；Build Profiles 無失效路徑。
- [ ] Play Mode、編譯與匯入中選單停用；一般 Player Build 不含 Editor 程式。

此工具依 Unity 官方 AssetDatabase.MoveAsset、EditorBuildSettings.globalScenes、BuildProfile.scenes API 實作；目前只有程式碼與文件靜態檢查，不能視為 Editor／Build PASS。
